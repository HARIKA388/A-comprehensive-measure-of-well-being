# A Comprehensive Measure of Well-Being

## Project Overview

A Comprehensive Measure of Well-Being is a Machine Learning project developed to predict the Human Development Index (HDI) using Linear Regression. The project analyzes the Human Development Index dataset, preprocesses the data, trains a machine learning model, evaluates its performance, and deploys the trained model through a Flask web application.

This project demonstrates the complete machine learning workflow, including data collection, preprocessing, model building, evaluation, model serialization, and deployment.

---

## Problem Statement

The Human Development Index (HDI) is an important indicator used to measure the overall development of a country. It is calculated based on various factors such as life expectancy, education, and income.

The objective of this project is to build a machine learning model that predicts the HDI value using different socio-economic indicators.

---

## Objectives

- Download and understand the Human Development Index dataset.
- Perform data preprocessing and cleaning.
- Handle missing values.
- Encode categorical variables.
- Split the dataset into training and testing data.
- Train a Linear Regression model.
- Evaluate the model performance.
- Save the trained model using Pickle.
- Develop a Flask web application for HDI prediction.
